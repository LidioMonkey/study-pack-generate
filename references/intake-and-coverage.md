# 资料盘点与覆盖图

## 输入识别

| 输入 | 提取重点 |
|---|---|
| PPT/PDF/Word | 标题层级、定义、公式、图表、例题、老师强调点、页码或 slide 编号 |
| 图片/手写笔记 | 题干、公式、图表、圈画、批注、易错标记 |
| 往年题/样卷 | 题型、分值、考点、难度、重复出现的表达 |
| 考试范围 | 章节边界、考试形式、是否开卷、剩余时间 |
| 网页/视频字幕 | 主题分段、时间线、案例、术语和链接 |

## 处理规则

1. 先列出所有资料，不要直接生成复习内容。
2. 资料较多时，按章节、模块、文件或题型切块；先快速浏览全部文件的结构（目录、标题、页数），交付覆盖图和重点速览，再逐块深读。
3. 每个资料块记录：文件名、页码或 slide、主题、可提取内容、无法识别内容。
4. 图片、扫描件、图表和公式不能静默跳过；识别不清时标注“需确认”。
5. 不要把资料外的内容混入“老师资料重点”。

## 覆盖图格式

```text
资料清单：
- 文件：
- 范围：
- 已读取：
- 未读取/无法识别：

章节覆盖：
- 第 1 章：
  - 已覆盖：
  - 缺口：
  - 相关题型：
```
