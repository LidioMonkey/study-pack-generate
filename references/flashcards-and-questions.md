# 闪卡与题库

## 闪卡规则

- 每张卡只测一个知识点。
- 优先使用主动回忆问题，不做只靠识别的真假题。
- 定义类概念可以生成正向和反向卡。
- 易混概念必须生成比较卡。
- 计算题只适合单步公式卡；多步骤计算进入练习题。
- 每张卡保留资料位置。

## 闪卡导出

交付闪卡文件时默认生成 `闪卡.csv`，可直接导入常见记忆卡片软件：

```text
Front,Back,标签
"什么是边际效用递减？","其他条件不变时，连续消费同一商品，每增加一单位带来的效用增量递减。","微观经济学/第3章"
```

- 编码用带 BOM 的 UTF-8（用 Excel 打开不乱码；Anki 等软件同样兼容）。
- 每个字段一律用英文双引号包裹，字段内的双引号写成两个双引号。
- 一行一卡，标签列写“课程/章节”或考点，便于导入后筛选。

## 题目类型

| 类型 | 使用场景 |
|---|---|
| 选择 | 快速检查概念、定义、公式适用条件 |
| 判断 | 只用于边界清晰的事实，不作为主要题型 |
| 填空 | 术语、公式、步骤、关键结论 |
| 简答 | 原理、机制、比较、解释原因 |
| 论述 | 综合分析、案例、开放表达 |
| 计算 | 公式应用、多步骤推导、单位换算 |
| 实验/案例 | 实验流程、现象解释、方案设计 |

## 每题字段

```text
题干：
题型：
考点：
难度：
答案：
解析：
资料位置：
```

资料中没有依据的题目必须标为“拓展题”。
