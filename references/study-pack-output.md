# 复习包输出

## 默认结构

```text
1. 资料清单与覆盖情况
2. 章节知识树
3. 必会/应会/了解 分层重点
4. 易混点对照表
5. 高频术语表
6. 公式/模型/图表清单
7. 典型题型与考点映射
8. 分题型练习题
9. 答案与解析
10. 闪卡表
11. 复习计划
12. 考前一页速记
```

## 重点分层

| 层级 | 标准 |
|---|---|
| 必会 | 资料反复出现、往年题出现、老师明确强调、公式/定义/核心方法 |
| 应会 | 支撑核心题型的概念、典型比较、常见步骤 |
| 了解 | 背景、拓展、低频案例 |

## 输出要求

1. 章节标题与资料结构对齐。
2. 每个重点尽量标明资料位置。
3. 题型总结只基于已提供资料和往年题。
4. 不要声称“老师一定会考”；可以说“根据已提供资料，这类题型出现频率较高”。
5. 用户要求文件时，按当前环境可用能力生成文档、表格或简版文本。
6. 写入文件时，复习包正文放 `复习包-<课程名>/复习包.md`，按默认结构编号组织；复习计划、闪卡、速记页拆成独立文件，方便单独打开使用。
7. 考前一页速记控制在一页以内：只放必会层重点、易混对照和高频公式，不复制完整解释。

## Markdown 排版规范

写任何 .md 产物时必须遵守，交付前自查一遍：

1. 表格单元格内禁止出现裸竖线 `|`，否则表格会被撑破。处理顺序：优先转义写 `\|Ed\|`；渲染环境不认转义时用 `&#124;`；表格单元格的行内代码里两种转义都无效，所以单元格内的行内代码禁止含竖线，改写成「Ed 的绝对值」。全文风格保持一致。
2. 公式写法全文统一：行内公式用反引号包裹（如 `Ed = (ΔQ/Q) / (ΔP/P)`），下标用普通字符（Q1、P2），不要混用 Unicode 上下标（Q₂、P₁）和普通字符。
3. 多步推导不塞进表格单元格；放在代码块或编号列表里，一步一行。
4. 禁止用 ASCII 字符画曲线图、函数图；图形要点改用文字描述（如「MC 先降后升，依次从下方穿过 AVC、AC 的最低点」），可视化版本放进 HTML 产物。
5. 章节之间用 `---` 分隔可以，但不要在表格前后紧贴加粗长句堆 emoji；每个表格上方有一句话说明用途。
6. 交付前用渲染视角检查：表格列数对齐、代码块闭合、列表缩进一致。

## HTML 产物规范

`考前速记.html`（以及用户要求的 `复习包.html`）一律以 `assets/study-pack.html` 为模板替换内容，不从零写样式。硬性要求：

1. 单文件自包含：CSS 写在 `<style>`、JS 写在 `<script>`，不引用本地外部资源；外部只允许模板里已有的公式渲染 CDN，且必须保持模板的守卫式写法——断网时公式以 `$...$` 源码原样可读，页面其余部分不受影响。
2. 数学公式一律放进 `$...$` / `$$...$$` 定界符写 LaTeX（绝对值、条件概率等含竖线的内容从根上避开表格语法冲突）；`throwOnError: false` 保持不动。
3. 视觉纪律：保持模板的 CSS 变量色板（`--bg/--surface/--border/--text/--text-dim/--accent/--warn`），主色占 60-70% 视觉权重，只换 `--accent` 不加新色相；禁止紫色渐变、彩虹配色、emoji 当章节图标、大段居中正文。结构元素（编号、眉题、色条）必须承载信息，不做纯装饰。
4. 打开 5 秒内可懂：页头必须有课程名、考试时间和范围；每个区块有明确标题。
5. 信息密度优先：速记页用多栏密排，知识块 `break-inside: avoid`；内容多于一页时砍内容（只留必会层），不缩字号。
6. 保留模板的 `@media print` 块，A4 打印不破版、色块不丢失。
7. 自查：把样式换成无设计的默认主题后如果没人察觉区别，说明没有设计，重做；检查没有内容溢出或互相重叠。
